# Report generation Skill

Organize penetration testing results into structured reports with detailed findings、PoC Scripts and fix suggestions.

## Report structure

### 1. Project overview
- Test target
- Test time
- Test range
- Test method

### 2. executive summary
- High-risk findings overview
- Risk level distribution
- Key recommendations

### 3. Detailed findings
For each vulnerability:
- Vulnerability name and severity level
- Vulnerability type
- Scope of influence
- Verification steps
- key evidence (request/response/screenshot)
- PoC Script
- Repair suggestions

### 4. attack path
- Complete attack chain diagram
- Path from initial access to final destination

### 5. appendix
- PoC Script
- Traffic packet capture
- Screenshot evidence
